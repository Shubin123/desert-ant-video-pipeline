GridGraph

Each stage runs in its own sandboxed frame, one at a time. Select any stage to run it alone, with everything it depends on, or with everything after it. Drag cards and panels to rearrange them, or use Alt + arrow keys. Dashed edges are the Laya failover path.

Edit the workflow in the graph: drag from a stage’s ● port onto another stage to make it run after it, select a connection and press Delete (or its ×) to remove it, and include or exclude stages from their stage panel. Every run follows the workflow.

    3 · Review and splice voice-over
    The worked examples have curated timelines, original-speed narration, and silent diagram holds. Edit the JSON if needed; the exporter validates every boundary and frame. No synthetic narration is supplied.

    4 · Export and verify
    MP4 export uses your browser’s H.264/AAC encoders at exactly 30 fps. If unsupported, download the timeline and use the documented local FFmpeg renderer. Laya cannot replace a video encoder.
